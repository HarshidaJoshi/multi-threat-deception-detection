# XAI-Verify — 4-Page PPT Design

Presentation mockups matching the dissertation poster layout (Dashboard, DeepFake, Fake News, Recruitment Scam).

## Open in browser

```powershell
start docs\presentation\index.html
```

Or double-click `docs/presentation/index.html`.

## Slides included

| Slide | Content |
|-------|---------|
| **Overview** | Title, system architecture diagram, technology stack |
| **Page 1** | Web Application Dashboard |
| **Page 2** | DeepFake Image Detection (Grad-CAM + forensics) |
| **Page 3** | Fake News Detection (LIME word bars) |
| **Page 4** | Recruitment Scam Detection (trust score + risk indicators) |

Each slide is **1280×720** (16:9) — ideal for PowerPoint.

## Add to PowerPoint

1. Open `index.html` in Chrome or Edge.
2. Scroll to each slide.
3. **Windows:** `Win + Shift + S` → capture the slide area.
4. Paste into PowerPoint (`Ctrl + V`).

**Or export as PDF:**

1. `Ctrl + P` → **Save as PDF**
2. In PowerPoint: **Insert → Pictures → This Device** (one image per slide)

## Files

- `index.html` — all slides
- `ppt-mockup.css` — styling (dark sidebar, cards, charts)
